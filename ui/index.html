Como conectar o Gemini Spark / Agente

Use o Link Público + header Authorization: Bearer <TOKEN>.

  • GET /screen — Captura a tela (PNG base64)
  • POST /mouse/click — Clica na tela (x, y)
  • POST /keyboard/type — Digita texto
  • POST /terminal/exec — Executa comandos no terminal
  • GET /openapi.json — Especificação OpenAPI para agentes
