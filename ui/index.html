❓ Como conectar e resolver erros
  1. Clique em Iniciar Conexão e aguarde o status ficar Online.
  2. Copie a URL Completa para MCP (termina em /mcp?token=...).
  3. Na aba Configuração do cliente MCP, escolha seu cliente e copie o JSON.
  4. Cole a configuração no cliente e reconecte.

Erro “Não foi possível acessar o servidor MCP. Revise o URL”?

  • Use a URL com /mcp (não apenas /) e com o token atual.
  • Se o cliente permite headers, use Authorization: Bearer <token> e a URL sem ?token=.
  • Confira se o Spark Bridge está Online e clique em Testar conexão MCP.
  • URLs do Cloudflare Quick Tunnel mudam a cada início — copie a URL nova após reconectar.
