Guia rápido e solução de problemas
  1. Na aba Conexão, clique em Iniciar Conexão e aguarde o status Online.
  2. Copie a URL Completa para MCP (terminando em /mcp?token=...) ou o snippet JSON acima.
  3. Cole no seu cliente de IA e recarregue o servidor MCP.

Erro “Não foi possível acessar o servidor MCP”?

  • Verifique se a URL termina exatamente em /mcp com o token atual.
  • No Cloudflare Quick Tunnel, uma nova URL é gerada a cada reinício.
